# Core Engines

## 1. Decision Engine

Determines whether a trader should take a trade.

---

## 2. Psychology Engine

Detects emotional mistakes.

Examples:

- Revenge Trading
- FOMO
- Overconfidence
- Fear

---

## 3. Risk Engine

Protects trader capital.

Examples:

- Daily Loss Limit
- Position Size
- Risk Reward
- Max Trades

---

## 4. Learning Engine

Converts every trade into a lesson.

---

## 5. Performance Engine

Measures improvement over months instead of daily P&L.
